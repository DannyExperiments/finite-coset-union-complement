# Public repository manifest

This is the clean public-facing repository candidate. The private evidence
archive is a separate, more comprehensive record and is not intended to be
made public wholesale.

## Included lanes

- root project status, provenance, contribution, and reproducibility records;
- a concise self-contained proof of the headline theorem and sharpness;
- two exact Lean 4.30.0 core sources, dependency pins, and replay reports;
- public-safe mathematical, literature, extension, and Lean audit summaries;
- the exact finite regression checker and recorded output;
- pinned GitHub workflows for repository verification, both Lean
  certificates, and a clean manuscript build;
- the independently accepted provenance-reconciled V2.2 manuscript, build and
  preflight records, and exact source-comparison summaries;
- release citation metadata naming DannyExperiments as conventional author;
- release notes for the intended `v1.0.0` archival snapshot;
  and
- discovery-route attribution for the UnsolvedMath dataset, separated from
  the official source authority.

## Deliberately excluded

- third-party source PDFs;
- raw ChatGPT task/project receipts and URLs;
- private model-return transcripts;
- old manuscript and solver ZIPs;
- handoff directories and duplicated extracted packet trees;
- local `.lake` products, page-render contact sheets, and temporary build
  records;
- account-identifying Aristotle submission receipts, raw external wrappers,
  and request identifiers; and
- stale private-campaign status files.

The checksum ledger covers the installed V2.2 public manuscript surface.
