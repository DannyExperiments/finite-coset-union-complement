# Security policy

This repository contains mathematical text, Lean source, and a standard-library
Python regression checker. It should not require credentials, downloaded
binaries, browser extensions, or unpinned install scripts.

Report exposed credentials, personal data, malicious changes, unsafe archive
contents, checksum inconsistencies, or dependency-supply-chain risks
privately. Do not include secrets in an issue or commit.

Mathematical objections belong in a proof-audit issue and should identify the
first disputed inference or an exact counterexample.
