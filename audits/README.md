# Audit records

This directory contains public-safe summaries of the independent audit lanes.
The complete raw model returns, receipts, task URLs, private package trees, and
immutable solver archives remain in the private evidence repository.

These reports keep four questions separate:

1. Is the mathematical proof valid at the stated scope?
2. What does the Lean certificate actually prove?
3. What prior work was located?
4. Is the artifact ready to release?

An AI-audit PASS is not human peer review, and a negative literature search is
not an absolute priority certificate.
