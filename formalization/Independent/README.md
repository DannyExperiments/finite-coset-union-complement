# Independent pre-Aristotle certificate

`Kourovka21115Independent.lean` is the repository's earlier Lean 4.30 proof
of the headline theorem. It was preserved verbatim when the externally
returned Aristotle reconstruction was ported into the canonical source slot.

It exports `Kourovka21115.kourovka_21_115`, uses a direct matrix
factorization through `Finset (Fin n)`, and builds under the same pinned Lean
and Mathlib environment as the canonical certificate.

The accompanying pre-Aristotle report and build record are historical
snapshots. Current dual-certificate status is documented one directory above.
