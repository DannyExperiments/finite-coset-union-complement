# Release notes v1.0.0

This release presents a complete proof of Kourovka Notebook Problem 21.115:
every proper union of `n` arbitrary left or right cosets in a finite group
misses at least a `2^-n` fraction of the group.

The release includes:

- the self-contained Version 2.2 manuscript and concise proof;
- two distinct Lean 4.30/Mathlib certificates of the headline theorem;
- mathematical, literature, extension, and formalization audit summaries;
- a dependency-free finite regression checker and frozen output;
- pinned GitHub Actions workflows for repository, Lean, and PDF replay; and
- a complete SHA-256 ledger for the public research surface.

The installed manuscript PDF has SHA-256
`6c82c218005037974992d9704324df8e17ea9df19e9b5cc79675be0be6cf96e9`.

The documented literature search found no identical proof and supports only
the qualified description "apparently new, moderate confidence." Human
specialist review and absolute historical priority are not claimed.
